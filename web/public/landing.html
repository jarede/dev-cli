Um canivete suíço em Rust, escrito para aprender

Os seus logs e os seus custos de IA, num só binário.

O dev-cli acompanha os containers da sua VM — erros, 5xx, p95 — num dashboard de terminal ou num portal web, e ainda fecha a conta do mês com o Claude Code e o OpenCode, em dólar e em real.

brew install dev-cli Como funciona

Três frentes, um binário

Logs ao vivo

Coleta contínua dos containers — docker local ou via SSH — com containers ranqueados por severidade, drill-down por nível e alertas quando algo para ou reinicia.

Portal web

O dev-server expõe a mesma coleta numa API JSON e serve o portal no navegador: feed de erros em tempo real, tabela de containers e histórico por hora.

Custos de IA

Heatmap de atividade, streaks e custo por modelo do OpenCode e do Claude Code — lidos direto dos arquivos locais, convertidos pela cotação do dia.

Instalação

Binários para macOS, Linux e Windows em cada release — com checksums.

macOS e Linux — Homebrew
brew tap jarede/dev-cli https://github.com/jarede/dev-cli
brew install dev-cli
Windows — Scoop
scoop bucket add dev-cli https://github.com/jarede/dev-cli
scoop install dev-cli
A partir do código-fonte
cargo install --git https://github.com/jarede/dev-cli
